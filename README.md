# Mesa Urban Transit Expansion & Emissions Impact Analysis

## Project Overview
#### This project involved GIS-based transit planning and emissions modeling for underserved regions of Mesa, Arizona.

## Methods

* Spatial Analysis: Used QGIS to analyze census tracts, identify transit gaps, and apply choropleth mapping.

* Route Design: Proposed 5 new bus routes with 45 stops, digitized using major arterials.

* Accessibility Modeling: Applied 500m buffer zones to new routes to simulate pedestrian access.

* Impact Assessment: Modeled CO₂ emissions reductions under diesel and electric bus scenarios with varying ridership uptakes.

* Visualization: Created maps, bar charts, and carbon equivalency comparisons to support recommendations.

## Deliverables

* QGIS project files (.qgz)

* Proposed bus route shapefiles

* CO₂ emissions impact models (Python scripts)

* Final presentation slides and figures

* Final Report

# Tools & Technologies

QGIS · Python · Matplotlib · Geopandas · Public Data (ACS, OpenStreetMap)
